# Wedding invitation

Static wedding invitation for Omar and Reham. It has no build step and no remote Canva/JoyInvites dependency.

## Preview

Open `index.html` directly, or serve the folder with any static web server.

## Deploy to Vercel

Import this folder as a Vercel project. Leave the framework preset as **Other** and the output directory empty.

The `.vercelignore` file excludes `_source-backup`, which contains the original browser-save files and archive.
